Ce qu'on fait de vos données

Quand vous réservez un rendez-vous, on vous demande le nom de votre établissement, votre prénom, votre numéro de téléphone, le créneau choisi, et, si vous le dites, le type d'établissement. Rien d'autre.

  • Pourquoi. Organiser le rendez-vous, vous le confirmer et vous prévenir si quelque chose change, par SMS ou WhatsApp. C'est ce qui précède un devis : on n'a pas besoin de votre accord écrit pour ça, et on ne s'en sert pour rien d'autre.
  • Qui les voit. Les trois personnes de Devanturo, et personne d'autre. Si on vous envoie un SMS, le message passe par un prestataire d'envoi, qui ne voit que votre numéro et le texte.
  • Où. Le site lui-même n'enregistre rien sur un serveur : le créneau et le nom que vous tapez restent dans votre navigateur (jusqu'à ce que vous effaciez ses données) et nous arrivent par le message WhatsApp ou l'appel que vous nous envoyez. On les note ensuite dans notre agenda.
  • Combien de temps. Douze mois après le rendez-vous, puis effacement automatique. Si on travaille ensemble ensuite, vos coordonnées passent dans le dossier de votre site, comme pour n'importe quel client.
  • Vos droits. Voir, corriger ou faire effacer ce qu'on a sur vous : un message sur WhatsApp ou 06 14 97 96 04 suffit, on le fait dans la journée. Si vous n'êtes pas satisfait, vous pouvez écrire à la CNIL, cnil.fr.

Ce site ne pose aucun cookie et n'utilise aucun outil de mesure d'audience. Il garde seulement dans votre navigateur, chez vous, votre choix clair ou sombre et le rendez-vous que vous avez pris, pour pouvoir le retrouver. Les polices d'écriture sont chargées depuis Google Fonts, qui reçoit alors votre adresse IP, comme pour n'importe quelle image chargée depuis un autre site.
